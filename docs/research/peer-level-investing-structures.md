# Peer-Level Investment Structures Research

> Research on non-hierarchical investment organizations that outperformed or matched markets.

---

## Key Models Studied

### 1. Beardstown Ladies Investment Club (1983)
- 16 women, monthly meetings, $25/month contributions
- **"Stock Watcher" role** — each member assigned 1-3 stocks to monitor and report on. This is the most transferable idea: distributed persistent surveillance with individual accountability
- Used NAIC Stock Selection Guide (SSG) as standardized analytical framework
- Majority vote, one member one vote
- Actual returns ~9.1% annualized (roughly matched S&P 500 — notable for amateurs who typically underperform by 3-5%)

### 2. NAIC / BetterInvesting Model (1951, peaked at 37K clubs)
- 10-20 members, monthly meetings, structured agenda
- **The SSG (Stock Selection Guide)** — standardized one-page framework: 10yr revenue/earnings growth, profit margins, P/E history, 5yr projected high/low price, requires 3:1 upside/downside ratio
- Meeting format: treasurer report → stock watcher updates → education segment → new stock presentations → vote
- Some clubs required 2/3 supermajority for sells (enforced long-term holding)
- Academic finding (Barber & Odean 2000): average club underperformed by 3.8%, BUT clubs that rigorously followed SSG methodology significantly outperformed those that deviated

### 3. Motley Fool Community Model (1993)
- Stock-specific message boards with deep analysis communities
- **CAPS Rating System** — prediction-market-like system where members rated stocks outperform/underperform, earned 1-5 star rating based on track record accuracy
- Community aggregate 5-star stocks did tend to outperform 1-star stocks (collective intelligence evidence)
- Transparent track records eliminated cheap talk
- Failed when: community scaled too large (noise exceeded signal), commercialized away from peer model

### 4. Tiger Cubs / Julian Robertson's Seeding Model (2000+)
- Robertson trained analysts inside Tiger Management, then seeded them as independent PMs with $25-50M + his reputation
- **The peer network**: Tiger Cubs shared ideas through conferences, informal calls, common analytical language (fundamental L/S)
- Independent convergence as signal — multiple Cubs reaching same conclusion independently = high conviction
- Cubs collectively managed $100B+, many returned 15-25% annualized over 10+ years
- **Failure mode**: correlated positions across the network created systemic risk (Tiger Global -50% in 2022)
- **Key takeaway**: Train in common framework → operate independently → share ideas → use independent convergence as signal

### 5. Good Judgment Project / Superforecasters (2011)
- Funded by IARPA, competed against intelligence analysts with classified access
- Top 2% ("superforecasters") outperformed professionals by 30%+
- **Superforecaster teams of ~12** improved accuracy an additional 23% over individual superforecasters and beat prediction markets by 15-30%
- Teams used async online discussion, each member posted forecast WITH reasoning
- Aggregation: **extremized mean** — average probabilities, then push further from 50% by calibrated factor (1.5-2.5x)
- Key traits: drew on many frameworks (foxes not hedgehogs), granular updates, actively sought disconfirming evidence

### 6. Prediction Markets (Polymarket, etc.)
- Skin in the game filters uninformed opinions
- Marginal trader theorem: even if 90% are noise, 10% informed traders set the price
- Self-correcting through profit incentives
- Weakness: manipulable when thin (low liquidity), long-shot bias

## Universal Success Factors

| Factor | Description |
|--------|-------------|
| **Analyze independently, then share** | Every successful model has individuals doing research BEFORE presenting. Prevents anchoring/groupthink |
| **Standardized framework, not conclusions** | SSG, Rule Breaker criteria, fundamental L/S — common language makes research comparable and debatable |
| **Transparent cumulative track records** | CAPS ratings, Brier scores, fund returns — historical accuracy visible, creates earned meritocracy |
| **Independent convergence as signal** | Multiple analysts reaching same conclusion through different paths = higher conviction |
| **Structured dissent** | Robertson's "tell me why I'm wrong", designated devil's advocates, mandatory bear case presentations |
| **Social process discipline** | Group creates friction against panic selling, FOMO buying, confirmation bias, overtrading |

## Universal Failure Modes

| Failure | Description |
|---------|-------------|
| **Single member dominance** | One persuasive person destroys the peer structure |
| **Abandoning the framework** | Chasing hot tips instead of following standardized analysis |
| **Correlated positions** | Shared analytical DNA leads to crowded trades (Tiger Cubs problem) |
| **Action bias** | Feeling obligated to buy something every meeting |
| **Noise scaling** | Quality degrades as group grows too large |

---

## Implications for Multi-Agent Hedge Fund

1. Each agent should complete independent analysis BEFORE group discussion
2. Need a standardized analytical checklist per domain (equivalent to SSG)
3. Track each agent's prediction accuracy over time — weight their input by track record
4. Use independent convergence detection: when 3+ agents reach same conclusion through different data, flag as high-conviction
5. Mandatory bear case for every bull thesis (and vice versa)
6. The "stock watcher" pattern: each agent monitors specific instruments/sectors and reports at meetings
7. Extremized mean for probability estimates on macro events
